# assets

Directory for screenshots and demo media referenced from the README.

## How to add screenshots

1. Run the app on your desktop and capture screenshots (PNG) or a short demo (GIF).
2. Put the files in this directory, e.g. `screenshot-countdown.png`, `demo.gif`.
3. Reference them from the README, e.g.:

```markdown
![countdown](./assets/screenshot-countdown.png)
```

This directory is kept with a `.gitkeep` placeholder so the folder exists
in the repository.
