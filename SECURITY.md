# Security Policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | ✅                 |

## Reporting a vulnerability

This project is a small local desktop widget with no network surface.
If you still find a security issue, please **do not open a public issue**.
Instead, reach out privately via the repository owner's contact information
on GitHub, and include a description of the issue and steps to reproduce.
